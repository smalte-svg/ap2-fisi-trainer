# ap2-fisi-trainer


https://smalte-svg.github.io/ap2-fisi-trainer/



💾 Lernstand-Code unter Mehr → Einstellungen: Ein Tipp auf „Code erstellen“, dann „Kopieren“ oder „Teilen“ und in Notizen speichern. Der Code ist etwa 600 Zeichen lang und enthält alles: Bewertungen, XP, Streak, Merkliste und Highscore.
Code einfügen funktioniert überall: iPhone ↔ Android, Safari ↔ Home-Bildschirm, alte ↔ neue Version. Der Stand wird zusammengeführt, pro Karte gilt die neuere Bewertung. Man kann also nichts versehentlich überschreiben.
Beim ersten Start auf einem neuen Gerät gibt es direkt den Button „Ich habe schon einen Lernstand-Code“.
Nach 15 geübten Karten erinnert eine Karte auf der Startseite einmal pro Woche an eine Sicherung.
In der Web-App erscheint nach einem Update „✅ App aktualisiert – dein Lernstand bleibt erhalten“. Das Icon muss nie gelöscht werden: App schließen und wieder öffnen reicht, nach ein bis zwei Starts ist die neue Version da.
